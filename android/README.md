# Android platform scaffold

This directory contains the initial Android Gradle/Kotlin host configuration for the Flutter app.

Important:
- Generate/refresh platform support using a compatible Flutter SDK before treating this scaffold as build-ready.
- The Gradle wrapper scripts and wrapper JAR are not included yet.
- `android/local.properties` is machine-specific and must not be committed.
- Package IDs are provisional: `com.example.edumanage_offline`; choose the production application ID before release.
- No build or tests have been run as part of adding these files.
